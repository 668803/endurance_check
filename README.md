# endurance_check
In order to facilitate the use of community doctors, we have developed a web small program that does not need to be installed and can be opened directly in the mobile browser. Based on the regression equation and correction formula from the paper, the program can estimate the corrected τSmO2 and provide the endurance level and exercise recommendations by inputting the number of sittings in 30 seconds and sebum thickness (or using the default gender value): Save the provided code as an "endurance_check.html" file. Transfer the files to mobile phones using WeChat's "file transfer assistant" or a USB connection. Open the file using a mobile browser such as Chrome, Safari, Huawei browser, etc. Follow the on-screen instructions to input the required data and then click on "start evaluation" to view the results.
